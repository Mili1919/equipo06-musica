# Nuestra Música(Spotify)

Proyecto de Software – UNLa – 2do cuatrimestre 2026 – Equipo 06

Es una app web para escuchar música en un solo lugar, sin tener que descargar nada.
La estamos haciendo con Scrum, en sprints de una semana.

## Equipo

- Milagros
- Erika
- Aixa
- Juan
- Jazmín

## Sprint 1 

Objetivo: que el usuario pueda ver el catálogo, elegir una canción, escucharla y pausarla.

- US01 Ver el catálogo de canciones → Erika
- US03 Reproducir una canción → Aixa y Juan
- US04 Pausar y reanudar → Jazmín
- Estructura base y pruebas → Milagros

## Cómo abrir la app

1. Abrir la carpeta con VS Code
2. Instalar la extensión Live Server
3. Clic derecho en index.html → Open with Live Server

## Cómo trabajamos con Git

- Cada uno trabaja en su propia rama (ej: us01-catalogo)
- Cuando termina, hace un Pull Request
- Otro del equipo lo prueba y lo aprueba antes de unirlo a main
- Nadie sube cambios directo a main

## Tecnologías

HTML, CSS y JavaScript. Las canciones que usamos son de prueba / libres de derechos.
